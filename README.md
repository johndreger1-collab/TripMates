# Tripmates

A free, mobile-first app for small groups who travel together, from rugby
weekends with friends to family holidays: shared places on a map,
independent ratings blended into a score, nearby filters, crawl routes,
check-ins and a drink tally, event-day mode, and a one-tap "Get me home".

Built like Level UP: a static PWA on GitHub Pages, an Apps Script JSON API, and
Google Sheets as the database. Everything is free.
